# Documento histórico — dirección Android reemplazada

Este documento conserva únicamente el registro de una decisión anterior del proyecto.

La dirección **Android-first** fue reemplazada el **1 de octubre de 2026** por una nueva decisión: Atlas Rivals se desarrollará inicialmente como **juego web adaptable**, accesible desde navegador tanto en teléfonos como en computadoras.

La especificación vigente se encuentra en:

- [`PLATAFORMA_WEB.md`](PLATAFORMA_WEB.md)

No deben tomarse las reglas antiguas de Android, Google Play Store o PC fuera de alcance como requisitos actuales de Guatemala 1.0.
