# Imágenes de cartas — Guatemala 1.0

Esta carpeta contiene las ilustraciones de las cartas del set inicial de Guatemala.

## Cartas iniciales

Subir una imagen por carta usando estos nombres:

- `kakik.png`
- `lago-de-atitlan.png`
- `ceiba-sagrada.png`
- `antigua-guatemala.png`
- `ciudad-de-guatemala.png`
- `juego-de-pelota-maya.png`

## Formato recomendado

- PNG o WebP.
- Orientación vertical.
- Mantener una proporción consistente entre todas las cartas.
- La imagen debe ser la ilustración principal de la carta; el marco, nombre, Vida, tipos y demás información los añadirá la interfaz del juego.

Las rutas públicas quedarán bajo `/cartas/guatemala/`.
